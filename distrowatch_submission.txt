Distribution Name: Kenosis Linux

Based on: Independent (Linux kernel + musl + kiss PM)
Origin: Unknown
Architecture: x86_64

Category: Minimalist, Experimental, Source-based
Status: Active

Description:
Kenosis Linux is an experimental operating system based on the Linux kernel, architected in strict adherence to the paradigm of radical architectural reduction and digital asceticism. It completely rejects shared libraries, using strictly statically linked binaries with musl libc, and uses cproc/QBE instead of GCC/LLVM for the base system. It features no graphics stack or systemd, relying on sinit, daemontools-encore, and POSIX-compliant shell scripts.
